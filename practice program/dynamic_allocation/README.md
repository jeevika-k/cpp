In this project, I implemented dynamic memory allocation using C++.
* Used pointers to store and access memory addresses.
* Allocated memory dynamically at runtime using the `new` operator.
* Stored values in dynamically allocated memory locations.
* Accessed and displayed data through pointers.
* Compared compile-time and runtime memory allocation concepts.
* Explored how memory is managed during program execution.
* Practiced pointer dereferencing to read and modify values.
* Learned the basics of dynamic array creation using user-defined sizes.
This project helped me understand pointers, dynamic memory allocation, runtime memory management, and efficient memory usage in C++.
